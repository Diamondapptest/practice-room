# ห้องซ้อมให้คำปรึกษา: คู่มือเปิดใช้งาน

เว็บฝึกให้คำปรึกษากับผู้รับบริการจำลอง ใช้ AI ของ Google (Gemini) แบบฟรี และวางเว็บบน Vercel แบบฟรี
ใช้เวลาตั้งค่าครั้งแรกประมาณ 30 นาที ไม่ต้องเขียนโค้ดเอง

---

## สิ่งที่ต้องมี

- บัญชี Google
- บัญชี GitHub (สมัครฟรีที่ github.com)
- บัญชี Vercel (สมัครฟรีที่ vercel.com โดยกด "Continue with GitHub")
- ไฟล์ในโฟลเดอร์นี้ (แตกไฟล์ zip ออกมาก่อน)

---

## ขั้นที่ 1: ขอ API key ฟรีจาก Google

1. เข้า **aistudio.google.com** แล้วล็อกอินด้วยบัญชี Google
2. กด **Get API key** (เมนูด้านซ้าย) แล้วกด **Create API key**
3. คัดลอก key ที่ได้ (ขึ้นต้นด้วย `AIza...`) เก็บไว้ในที่ปลอดภัย
   ห้ามโพสต์หรือส่ง key นี้ให้คนอื่น ใครได้ไปจะใช้โควตาของคุณได้

ไม่ต้องผูกบัตรเครดิต ถ้าหน้าจอถามให้ตั้งค่า Billing ให้ข้ามไป

---

## ขั้นที่ 2: อัปโหลดไฟล์ขึ้น GitHub

1. ล็อกอิน github.com แล้วกดปุ่ม **+** มุมขวาบน > **New repository**
2. ตั้งชื่อ เช่น `practice-room` เลือก **Private** แล้วกด **Create repository**
3. ในหน้าถัดไป กดลิงก์ **uploading an existing file**
4. ลาก **ทุกอย่างที่อยู่ข้างใน** โฟลเดอร์ `practice-room` ไปวาง ได้แก่ โฟลเดอร์ `api`, โฟลเดอร์ `public`, ไฟล์ `package.json`, `vercel.json` และ `README.md`
   ต้องลากของข้างในโฟลเดอร์ ไม่ใช่ลากตัวโฟลเดอร์ `practice-room` ทั้งก้อน
5. กด **Commit changes**

ตรวจว่าหน้า repository แสดงโฟลเดอร์ `api` และ `public` อยู่ชั้นบนสุด

---

## ขั้นที่ 3: เปิดเว็บบน Vercel

1. ล็อกอิน vercel.com แล้วกด **Add New… > Project**
2. เลือก repository `practice-room` แล้วกด **Import**
   (ถ้าไม่เห็น ให้กด "Adjust GitHub App Permissions" แล้วอนุญาต repository นี้)
3. **Framework Preset** เลือก **Other** ส่วนการตั้งค่าอื่นไม่ต้องแก้
4. เปิดหัวข้อ **Environment Variables** แล้วเพิ่มค่าดังนี้

   | Key | Value | จำเป็นไหม |
   |---|---|---|
   | `GEMINI_API_KEY` | key จากขั้นที่ 1 | จำเป็น |
   | `ACCESS_CODE` | รหัสที่คุณตั้งเอง เช่น `psy2026` | แนะนำ |

5. กด **Deploy** รอประมาณ 1 นาที
6. เมื่อเสร็จ Vercel จะให้ลิงก์หน้าตาแบบ `practice-room-xxxx.vercel.app` นี่คือเว็บของคุณ

---

## ขั้นที่ 4: ทดสอบ

1. เปิดลิงก์เว็บ เลือกเคส แล้วพิมพ์ทักผู้รับบริการ
2. ถ้าตั้ง `ACCESS_CODE` ไว้ ระบบจะขอรหัสในครั้งแรก ใส่รหัสแล้วกดส่งอีกครั้ง
3. คุยสัก 4–5 ข้อความ แล้วกด **ขอฟีดแบ็ก** มุมขวาบน

---

## รหัสเข้าใช้ (ACCESS_CODE) คืออะไร

โควตาฟรีของ Google มีจำกัดต่อวัน ถ้าลิงก์หลุดไปแล้วมีคนแปลกหน้าเข้ามาใช้เยอะ โควตาอาจหมดก่อนผู้ทดลองของคุณได้ใช้
การตั้งรหัสทำให้เฉพาะคนที่คุณให้รหัสเท่านั้นที่คุยกับ AI ได้

- ส่งลิงก์และรหัสให้ผู้ทดลองพร้อมกัน
- ผู้ทดลองใส่รหัสครั้งเดียว เบราว์เซอร์จะจำไว้
- อยากเปลี่ยนรหัส: Vercel > Project > **Settings > Environment Variables** แก้ค่า แล้วไปที่ **Deployments** กด **⋯ > Redeploy**

---

## ถ้ามีปัญหา

| อาการ | สาเหตุและวิธีแก้ |
|---|---|
| ขึ้นว่า "ผู้ดูแลยังไม่ได้ตั้งค่า GEMINI_API_KEY" | ลืมใส่ key ในขั้นที่ 3 ข้อ 4 ใส่แล้วกด Redeploy |
| ขึ้นว่า "API key ไม่ถูกต้อง" | คัดลอก key ไม่ครบ สร้าง key ใหม่แล้วแก้ค่า จากนั้นกด Redeploy |
| ขึ้นว่า "โควตาฟรีเต็มชั่วคราว" | มีคนใช้พร้อมกันเยอะ รอสักนาทีแล้วส่งใหม่ ถ้าเป็นบ่อย ดูหัวข้อถัดไป |
| ขึ้นว่า "ระบบขัดข้องชั่วคราว" ทุกครั้ง | ชื่อโมเดลอาจเปลี่ยน ดูหัวข้อ "เปลี่ยนโมเดล AI" |
| หน้าเว็บขึ้น 404 | ไฟล์อยู่ผิดชั้นใน GitHub ต้องเห็น `api` และ `public` ที่ชั้นบนสุดของ repository |

ดูรายละเอียดข้อผิดพลาดได้ที่ Vercel > Project > **Logs**

---

## เปลี่ยนโมเดล AI

ระบบลองโมเดลตามลำดับ ถ้าตัวแรกเต็มโควตาจะสลับไปตัวถัดไปให้เอง ค่าเริ่มต้นคือ

```
gemini-3.5-flash,gemini-3.1-flash-lite
```

Google เปลี่ยนรุ่นโมเดลบ่อย ถ้าต้องการเปลี่ยน:

1. ดูโมเดลที่ใช้ฟรีได้และโควตาของคุณที่ aistudio.google.com (เมนู **Rate limit** หรือ **Usage**)
2. ใน Vercel เพิ่ม Environment Variable ชื่อ `GEMINI_MODELS` ใส่ชื่อโมเดลคั่นด้วยจุลภาค เช่น `gemini-3.8-flash,gemini-3.1-flash-lite`
3. กด Redeploy

---

## ข้อควรรู้เรื่องข้อมูล

- บริการฟรีของ Google **อาจนำข้อความที่ส่งไปใช้พัฒนาโมเดล** จึงต้องบอกผู้ทดลองว่าห้ามพิมพ์ชื่อหรือข้อมูลของผู้รับบริการจริง (หน้าเว็บมีข้อความเตือนไว้แล้ว)
- เมื่อเริ่มเก็บเงินจากลูกค้า ควรเปลี่ยนเป็นแบบเสียเงินของ Google หรือ Claude API ซึ่งไม่นำข้อมูลไปฝึกโมเดล และทบทวนเรื่อง PDPA อีกครั้ง
- ข้อมูลส่วนที่ซ่อนของแต่ละเคสเก็บไว้ฝั่งเซิร์ฟเวอร์ (`api/_cases.js`) ผู้ฝึกเปิดดูจากเบราว์เซอร์ไม่ได้

---

## แก้ไขเคสหรือเพิ่มเคสใหม่

- ข้อมูลเคสที่ผู้ฝึกเห็น: `public/index.html` ค้นคำว่า `const CASES`
- บุคลิกและข้อมูลที่ซ่อนไว้: `api/_cases.js`
- เกณฑ์ให้คะแนน: `api/_cases.js` ในส่วน `FEEDBACK_PROMPT`

ทั้งสองไฟล์ต้องมีเคสที่ `id` ตรงกัน แก้ไฟล์ได้บนหน้าเว็บ GitHub (เปิดไฟล์แล้วกดรูปดินสอ) เมื่อกด Commit แล้ว Vercel จะอัปเดตเว็บให้อัตโนมัติ
หรือส่งไฟล์กลับมาให้ Claude ช่วยแก้ก็ได้
